# Réussir Bac Libre Maroc

Première maquette responsive en HTML, CSS et JavaScript.

## Contenu
- `index.html` : structure et contenu de la page
- `style.css` : design responsive, animations et styles
- `script.js` : menu mobile, filtres de ressources, animations d'apparition et formulaire local
- `favicon.svg` : icône du site
- `robots.txt` et `sitemap.xml` : fichiers SEO de départ (à mettre à jour après publication)

## Prévisualiser
Ouvre `index.html` dans un navigateur récent. Une connexion internet est nécessaire pour charger les polices Google Fonts; le site reste lisible sans elles.

## Publier gratuitement avec GitHub Pages
1. Crée/connecte-toi à un compte GitHub.
2. Crée un dépôt public nommé `reussir-bac-libre-maroc`.
3. Téléverse les fichiers du dossier à la racine du dépôt.
4. Dans le dépôt, ouvre **Settings → Pages**.
5. Sous **Build and deployment**, choisis **Deploy from a branch**, branche `main`, dossier `/ (root)`, puis **Save**.
6. Attends la publication et ouvre l'adresse affichée dans Settings → Pages.

## Avant de promouvoir le site
- Remplace les ressources génériques par des liens et documents fiables que tu as le droit de partager.
- Ajoute des pages dédiées aux filières et matières, avec du contenu réellement utile.
- Mets à jour `sitemap.xml` avec l'URL réelle du site publié.
- Ajoute le site à Google Search Console et vérifie la propriété.
- Le formulaire actuel est local : il n'envoie ni ne stocke les idées. Il copie le texte dans le presse-papiers lorsque le navigateur le permet.
- Aucun classement Google n'est garanti; l'indexation peut prendre du temps.
